# Raio-X do Estoque

Demonstração aberta de uma central de decisão de estoque com armazém 3D: indicadores, fila de decisões com prioridade explicável, prontuário da posição, máquina do tempo (histórico e projeção), simulações "E se?", análises e plano de ação.

Todos os números são **dados de exemplo**, gerados para a demonstração.
